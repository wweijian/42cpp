# 42 C++ Modules

A series of C++ exercises from the 42 school curriculum, covering core language features from the ground up.

| Module | Topic |
|--------|-------|
| [cpp00](./cpp00) | Namespaces, classes, member functions — PhoneBook exercise |
| [cpp01](./cpp01) | Memory allocation (`new`/`delete`), pointers, references, file streams |
| [cpp02](./cpp02) | Ad-hoc polymorphism, operator overloading, Orthodox Canonical Form |
| [cpp03](./cpp03) | Inheritance and class hierarchies |
| [cpp04](./cpp04) | Subtype polymorphism, abstract classes, interfaces, virtual functions |
| [cpp05](./cpp05) | Exception handling and custom exception classes |
| [cpp06](./cpp06) | C++ type casts (`static_cast`, `dynamic_cast`, `reinterpret_cast`, `const_cast`) |
| [cpp07](./cpp07) | Templates and generic programming |
| [cpp08](./cpp08) | STL containers, iterators, and algorithms |
| [cpp09](./cpp09) | STL containers in practice — Bitcoin exchange and file I/O |
